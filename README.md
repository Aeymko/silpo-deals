# Знижки Сільпо

**Усі акції Сільпо, відсортовані від найбільшої знижки у відсотках.**

Сайт Сільпо показує акції за популярністю, і найвигідніші пропозиції губляться серед тисяч товарів.
Саме для цього й створено цей сайт: він завантажує всі акційні товари вибраного магазину й одразу ставить
нагору ті, де знижка у **%** найбільша. Товар за 9,99 грн замість 259 грн (−96%) буде першим, а не на
сороковій сторінці.

Сайт: **https://aeymko.github.io/silpo-deals/**

## Як це працює

- **Сортування за відсотком знижки — за замовчуванням.** Відсоток рахується з поточної і старої ціни
  (`(стара − нова) / стара`) без округлення, тож порядок точний; за однакового відсотка вище стоїть
  товар із більшою економією в гривнях.
- **Поріг знижки.** Повзунок «Знижка від» ховає все, що дешевшає менше ніж на заданий відсоток.
- **Ваш магазин.** Вибір будь-якого магазину Сільпо (за замовчуванням — просп. Берестейський, 94/1) або
  онлайн-доставки. Ціни та наявність беруться саме для нього.
- **Лише в наявності.** Товари, яких немає на полиці, відсікаються ще на боці API.
- **Типи акцій.** Цінотижики, Додаткові пропозиції, Акції Власного імпорту тощо — вмикаються кнопками.
- **Категорії й пошук** за назвою чи брендом, а також інші сортування: економія в грн, ціна, рейтинг.

Дані беруться з публічного API Сільпо прямо в браузері й кешуються на 30 хвилин; кнопка оновлення
завантажує їх заново. Налаштування зберігаються в `localStorage`.

## Розробка

```bash
npm install
npm run dev        # http://127.0.0.1:8765
npm run lint       # Biome
npm test           # Vitest
npm run build      # vue-tsc + Vite
```

Стек: Vue 3 (`<script setup>`, TypeScript), Vite, shadcn-vue на Reka UI, Tailwind CSS 4, VueUse, Biome,
Vitest. Структура — [Feature-Sliced Design](https://feature-sliced.design/):

```text
src/
  app/        точка входу, глобальні стилі
  pages/      deals — сторінка й синхронізація фільтрів із завантаженням
  widgets/    app-header, deals-filters, deals-grid
  features/   select-branch, search-deals, sort-deals, filter-category,
              filter-promotion, filter-discount, toggle-in-stock, toggle-theme
  entities/   product (знижка, каталог, картка), branch, category, promotion
  shared/     api/silpo, lib, config, ui (shadcn-vue)
```

Кожен push у `main` проходить lint → test → build і публікується на GitHub Pages.

Проєкт неофіційний і не пов'язаний із Сільпо.
